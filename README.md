# PUNCH FACE — 링 위의 표정들

표정이 살아있는 2D 권투 게임. 설치/빌드 없이 `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다.
(Chrome / Edge 권장. 외부 라이브러리·이미지·사운드 파일 없음 — 캐릭터, 표정, 효과음 전부 코드로 생성)

## 휴대폰으로 플레이
1. **같은 Wi-Fi**에 PC와 휴대폰을 연결
2. PC에서 `휴대폰으로 열기.bat` 실행 → 표시되는 `http://192.168.x.x:8080` 주소를 휴대폰 브라우저에 입력
3. 가로로 돌리면 화면 양쪽에 터치 버튼이 나타납니다 (자동 감지, 타이틀의 "터치 조작"으로 수동 전환)

터치 조작: 왼쪽 `◀ ▶` 이동 · `가드`(누르고 있기) · `더킹` / 오른쪽 `잽` `스트` `훅`(좌우 번갈아) `어퍼` · `슬립`
`더킹`을 누른 채 펀치 = 바디샷. 넉다운 시 펀치 버튼 연타로 기상.

## 🏆 챔피언 로드 (커리어)
- 선수 한 명을 골라 세계 랭킹 8위부터 시작. 바로 위 랭커를 이기면 한 계단 상승, 1위(챔피언)를 이기면 **세계 챔피언** → 이후 상위 랭커의 도전을 받는 **타이틀 방어전**
- 경기마다 포인트 획득(승 3, KO +1, 방어전 +1, 패 1) → **능력치 강화**(파워/스피드/체력/맷집/회복/방어 +1) 또는 **고유 스킬 강화**(Lv.3까지, 레벨당 위력 +15%·게이지 +25%)
- 전적·랭킹 변동이 히스토리에 기록되고 브라우저에 자동 저장(localStorage)
- 난이도는 랭킹에 따라 자동 상승 (8~7위 쉬움, 6~4위 보통, 3위~챔피언 어려움)

## 고유 스킬 · 콤보 · 패리
- **스킬 게이지**: 펀치를 맞히거나 막거나 맞으면 충전. 가득 차면 `L` / 스킬 버튼
  | 선수 | 스킬 | 효과 |
  |---|---|---|
  | 강태산 | 불도저 러시 | 훅·훅·바디훅·어퍼 4연타, 발동 중 피격에 밀리지 않음 |
  | 라이언 | 메트로놈 잽 | 초고속 잽 4연타 + 스트레이트 |
  | 이반 | 해머 스트레이트 | 방어 불가 2.6배 스트레이트 |
  | 사토 | 미러 카운터 | 2.5초간 모든 공격을 흘리고 2배 카운터 |
  | 디에고 | 벌떼 바디 | 바디 4연타 + 어퍼컷 |
  | 제임스 | 썬더 어퍼컷 | 방어 불가, 넉다운 확률 +35% |
  | 박만수 | 노장의 철벽 | 3초 완전 방어 + 체력/스태미나 회복 |
  | 은하 | 번개 스텝 | 순간 접근 후 6연타 |
- **연속 콤보** (적중 순서): 잽·잽·스트 = 원투(×1.5) / 잽·스트·L훅 = 1-2-3(×1.7) / 바디·바디·어퍼 = 바디 어퍼(×1.9, 그로기) / 스트·어퍼 = 크로스 어퍼(×1.5) / L훅·R훅 = 더블 훅(×1.4)
- **패리**: 상대 펀치가 닿기 직전(8프레임 안)에 가드를 올리면 노대미지 + 상대 경직 2배 + 스킬 게이지 +15
- **일시정지/나가기**: 화면 오른쪽 위 ⏸ 또는 ESC

## 조작 모드
- **쉬움 (기본)**: 거리는 자동. `잽` `스트` `훅`(좌우 교대) `어퍼` 버튼 · `바디`를 누른 채 펀치 = 바디샷 · `가드`(홀드, 바디 부분 방어) · `회피` · `스킬`. 키보드 J/K/U/I/O · S+펀치 · Space · Q · L.
- **정밀**: 전체 버튼(이동·더킹·잽/스트레이트/훅/어퍼컷·슬립). 타이틀 화면 "조작"에서 전환.

## 그래픽 · 연출
- AI 생성 스프라이트(8명 × 12포즈 + 레퍼리). HUD 초상화는 현재 포즈의 얼굴을 실시간으로 잘라 보여줌
- 타격: 히트스톱 · 섬광 · 충격 링/스타버스트 · 집중선 · 카메라 펀치인 · 강펀치/스킬/슬립 잔상
- 연출: 라운드 시작 플래시, KO 시네마(레터박스 + 슬로모션 + 줌), 실황 캡션, HP 잔량 고스트 바, 저체력 비네트
- 타이틀 화면 뒤에서 AI끼리 스파링(어트랙트 모드), 마우스 이동에 따른 패럴랙스

## 모드
- **CPU 대전**: 내 선수만 선택, 상대는 CPU가 랜덤 배정(같은 선수 제외), 난이도 3단계
- **2인 대전 (온라인)**: 한쪽이 **방 만들기**로 4자리 코드를 만들고, 상대가 **참가하기**에 코드를 입력하면 다른 PC/휴대폰끼리 대결. 서버 없이 WebRTC(PeerJS 공개 시그널링)로 직접 연결 — 양쪽 모두 인터넷 필요. 방을 만든 쪽(호스트)이 경기를 계산하고 상대는 입력을 보내 화면을 받습니다. claude.ai 웹 링크 안에서는 연결이 차단되므로 PC의 index.html 또는 `휴대폰으로 열기.bat` 주소로 접속하세요. 같은 키보드로 하는 로컬 2P도 남겨 두었습니다.
- **CPU 관전**: AI끼리 싸우는 걸 구경 (스타일 상성 확인용)

|---|---|---|
| A / D | ← / → | 이동 |

## 핵심 룰
- 머리 타격 → HP 감소, 바디 타격 → 바디 대미지 + 스태미나 대량 소모 + 이동 둔화
- 스태미나 25 미만: 위력 0.65배, 느려짐, "지침" 표정
- 상대가 펀치 예비동작일 때 맞추면 **카운터** (1.5배)
- HP 0 이하 또는 강타 확률로 **넉다운** → 10카운트, 한 라운드 3넉다운 = TKO
- 라운드 10점제 판정, 넉다운 시 -1점
